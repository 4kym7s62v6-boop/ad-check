# AdCheck — 무료 광고 표현 점검 웹사이트

외부 AI API와 유료 서비스, npm 패키지 없이 실행하는 한국어 광고 표현 점검기입니다.

## 시작하기

1. Node.js 20 이상 설치
2. 이 폴더에서 터미널을 열고 `npm start` 실행
3. 브라우저에서 `http://localhost:3000` 접속

## Render 무료 웹 서비스에 올리기

1. 이 프로젝트 폴더 전체를 GitHub 저장소에 업로드
2. Render에서 **New > Web Service** 선택 후 해당 GitHub 저장소 연결
3. Runtime: **Node**, Build Command: `npm install`, Start Command: `npm start`
4. 무료 플랜이 선택되어 있는지 확인하고 배포 (Render의 현재 정책과 요금은 직접 확인)

`render.yaml`로 Blueprint 배포도 가능합니다.

## 주의사항

- 외부 API 없이 사전에 정의한 문구 규칙만으로 0~100점을 계산합니다. **실제 허위광고일 확률, 법적 위반 판단, AI 판정이 아닙니다.**
- 링크의 HTML을 서버에서 직접 가져옵니다. 로그인, 일부 광고 플랫폼, 봇 차단, 브라우저 자바스크립트 렌더링 페이지는 읽을 수 없습니다. 그때는 ‘문구로 분석’ 이용.
- 링크를 읽지 못하면 점수를 만들지 않고 오류를 보여줍니다.
- 저장 기록은 브라우저 로컬 저장소에만 남으며 서버에 저장되지 않습니다.
- URL 안전을 위해 내부 네트워크 주소를 차단하고 있습니다. 공개 인터넷에 운영할 때는 DNS 재바인딩 방지, 프록시 및 네트워크 아웃바운드 제어 등 추가 보안 강화가 필요합니다.
- 광고의 사실을 검증하는 것이 아니라 과장 가능성이 있는 표현을 표시하는 교육용 도구입니다.
